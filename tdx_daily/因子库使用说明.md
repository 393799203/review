> 服务器：124.221.228.215，代码 `/opt/stock-review/tdx_daily/`

## 1. 因子表总览

**表：`tdx.raw_stock_indicators`**（宽表，`UNIQUE(symbol, date)`，2026-09-05 精简为 **26 个因子**：核心技术 14 + 基本面 12，全市场含指数/板块，2025-09-01 起）

| 类别 | 列 |
|---|---|
| 技术-趋势(4) | dif, dea, mom20, mom60 |
| 技术-摆动(1) | rsi24 |
| 技术-量价(9) | vr10, vr20, vol_trend, vol_cv20, vol_pos20, corr_pv20, vpt, cmf20, mfi14 |
| 基本面-估值(4) | pe, pb, ps, pcf（calc_fundamental 计算） |
| 基本面-盈利(4) | roe, roa, net_margin, op_margin |
| 基本面-质量(4) | debt_ratio, cf_quality, ar_ratio, inv_ratio |

**精简依据**（2026-09-05 数据法医）：原 47 个技术因子按 ashare H5 中性化 |ICIR|≥0.25 筛选；其余 33 个（均线族/KDJ/CCI/WR/BIAS/BOLL/ATR/OBV/div20 等）`|ICIR|<0.25` 且多为风格贡献，**已从计算与表中删除**（含原推荐名单中的 atr14，实测 |ICIR|=0.13 不达标）。
- 口径：均线/量比类窗口**含当日**（vr10 = 当日量 / 10日均量）；量能类窗口 20 日；`corr_pv20` 为日收益×量变 20 对相关性
- 原始数据未删：`raw_stocks_basic` / `v_hfq_daily` / 复权因子等底表都在，日后要加回某因子仅需在 calc_indicator 的 COLUMNS 加一行并 `--full` 重算
- 数据不足的早期窗口为 NULL；`close` 不在因子表里，查价格请 join `raw_stocks_basic` 或 `v_hfq_daily`

## 2. 手动计算因子（一般不用手动，cron 已自动）

```bash
cd /opt/stock-review/tdx_daily
set -a && . ./.env && set +a        # 载入 DB_URL

python3 calc_indicator_standalone.py            # 增量（默认）：只补新交易日，秒级
python3 calc_indicator_standalone.py --full     # 全量重算（TRUNCATE 后重建，约 8-10 分钟）
python3 calc_indicator_standalone.py --limit-symbols 200   # 调试：只跑前 200 个标的
python3 calc_indicator_standalone.py --db-url "postgresql://..."  # 指定连接串
```

| 参数 | 说明 |
|---|---|
| `--db-url` | 连接串，缺省读 tdx_daily/.env 的 DB_URL |
| `--full` | 清空重算全量 |
| `--batch` | 每批插入行数（默认 5000） |
| `--limit-symbols N` | 只处理前 N 个标的（按 symbol 排序，调试用） |

增量幂等：重复运行输出 `已追平日线最新日，无需增量`；中断后可安全重跑（自动清理残尾）。

## 3. 因子有效性评估（IC/IR）

```bash
# 全部 47 个因子，H=5（未来5个交易日收益），近120交易日，5分位
python3 eval_factor_standalone.py --limit-dates 120

# 只看量价因子，H=10，近30交易日，导出逐日 IC 矩阵
python3 eval_factor_standalone.py \
  --factors vr20,div20,corr_pv20,cmf20,vol_cv20,obv_slope5 \
  --horizon 10 --limit-dates 30 --out-csv /tmp/ic_matrix.csv

# 指定日期区间 + 不分层
python3 eval_factor_standalone.py --min-date 2026-06-01 --max-date 2026-09-04 --quantiles 0

# 不剔除 ST
python3 eval_factor_standalone.py --no-exclude-st
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--horizon N` | 5 | 未来收益持有交易日数（1/5/10/20 常用） |
| `--factors a,b,c` | 全部 | 逗号分隔因子列名 |
| `--min-date / --max-date` | 全部 | 评估日期区间 YYYY-MM-DD |
| `--limit-dates N` | 0 | 只评估最近 N 个交易日（0=全部） |
| `--quantiles N` | 5 | 分层组数（0=不做分层） |
| `--min-stocks N` | 100 | 每日截面最少样本数 |
| `--no-exclude-st` | 剔除 | 默认剔除 ST（dim_sw_industry） |
| `--out-csv path` | 无 | 导出逐日 IC 矩阵（date × factor） |

**输出列解读**：
- `mean_ic` / `ic_std`：截面 Spearman 秩 IC 的均值/标准差
- `icir` = mean_ic / ic_std；`t_stat` = icir × √n（\|t\|>2 通常认为显著）
- `ic>0%`：IC 为正的交易日占比
- `Q1..Q5`：按因子值等频分 5 组，各组未来收益均值（Q1=因子值最小）
- `Q1-Q5_spread`：多头组-空头组收益差；`mono`：组序与收益的单调性（\|mono\| 越接近 1 越单调）

判读示例（H=5 近120日全市场）：
- `vol_cv20`：ICIR -0.42，t=-4.47 → 低量能波动（地量平稳）的股票未来 5 日表现更好，**负向因子**
- `cmf20`：分层 Q5>Q1 且 mono +0.90 → 资金持续流入的股票未来收益更高，**正向因子**
- 注意：当前为**原始截面 IC**，未做行业/市值中性化；binary 因子（new_high20/new_low20）分层分析退化，勿按分位解读

## 4. 直接用 SQL 选股/查因子

```sql
-- 当日全部量价因子（最新交易日）
SELECT * FROM tdx.raw_stock_indicators WHERE date = '2026-09-04';

-- 量价背离 + 资金流选股（含价格/换手，剔除ST，只留沪深个股）
SELECT i.symbol, b.close, b.turnover,
       i.div20, i.vr20, i.cmf20, i.mfi14, i.pos20
FROM tdx.raw_stock_indicators i
JOIN tdx.raw_stocks_basic b ON b.symbol = i.symbol AND b.date = i.date
LEFT JOIN tdx.dim_sw_industry d ON d.symbol = i.symbol AND d.is_latest = 1
WHERE i.date = '2026-09-04'
  AND (i.symbol LIKE 'sh60%' OR i.symbol LIKE 'sh68%'
       OR i.symbol LIKE 'sz00%' OR i.symbol LIKE 'sz30%')   -- 只留沪深主板/创业/科创
  AND (d.name IS NULL OR d.name NOT LIKE '%ST%')
  AND i.div20 < -0.2          -- 量价底背离
  AND i.vr20 BETWEEN 0.8 AND 1.5  -- 温和放量
  AND i.cmf20 > 0 AND i.mfi14 > 60 -- 资金流入
ORDER BY i.div20 ASC;

-- 最新日每个因子的横截面分布（检查是否有 NULL 或异常）
SELECT count(*) AS n, count(ma60) AS ma60_ok, count(div20) AS div20_ok,
       min(vr20), max(vr20) FROM tdx.raw_stock_indicators WHERE date = '2026-09-04';

-- 与复权视图联动：算"因子 + 未来收益"直接验证
SELECT i.symbol, i.div20, i.vr20,
       h.close / lag(h.close) OVER (PARTITION BY i.symbol ORDER BY h.date) - 1 AS ret
FROM tdx.raw_stock_indicators i
JOIN tdx.v_hfq_daily h ON h.symbol = i.symbol AND h.date = i.date;
```

注意：因子表含通达信指数/板块（sh88xxxx、bj43 等），**选个股务必按 symbol 前缀过滤**（00/30/60/68）。

## 7. 界面使用（已上线）

### 因子研究页（侧边栏「因子研究」，路由 /factor-research）
- 顶部可切换**样本**（全市场 / 沪深A股 / 沪深主板 / 创业科创）、**口径**（中性化IC / 原始IC）与**持有期 H=1/5/10/20**，表格按 |ICIR| 降序展示 47 个因子的 Mean IC / IC 标准差 / ICIR / t 值 / IC>0 占比 / Q1~Q5 超额收益 / Q1-Q5 价差 / 单调性
- **中性化IC**：因子值 − 申万一级行业当日均值 → 对 ln(总市值) 回归取残差（剥离行业与小市值风格）；**原始IC**：未中性化。两者并存可切换对比因子"纯不纯"
- **表头悬停「?」查看指标说明；悬停因子名查看该因子解释（47 个因子全部带类别+说明）**
- 「只看推荐」勾选后只显示推荐因子（低波异象 vol_cv20/atr14、量价背离 cmf20/vpt、长期动量反向 mom60，带「荐」标签）
- 点击因子行 → 下方显示该因子逐日 IC 时间序列 + 分位组超额收益柱状图
- 数据来源：`eval_factor_standalone.py --save` 落库的 `tdx.factor_eval_summary` / `tdx.factor_eval_daily_ic`（含 method=raw/neutral 两轨）
- 说明：默认「全市场」样本含指数/板块/北交所/基金等非个股标的（便于对照）；做个股研究建议用「沪深A股」样本（00/30/60/68）

### 量化选股页因子条件（可选）
- 筛选表单「因子条件（可选）」：添加 N 行 [因子] [比较符] [阈值]，支持 18 个常用量价/技术因子（div20/cmf20/mfi14/corr_pv20/vol_cv20/vr20/vol_trend/rsi12/kdj_j/macd_hist/bias12/mom20/std20/atr14 等）
- 作用于策略结果之上（突破放量/抄底放量均支持）；因子名后端白名单校验，防注入
- 每日 19:00 自动筛选同样会携带已保存的因子条件

### 重新评估（新增因子/改窗口后）
```bash
cd /opt/stock-review/tdx_daily && set -a && . ./.env && set +a
# 默认同时计算 raw（未中性化）与 neutral（行业均值+ln市值残差）两轨并落库 method=raw/neutral
# --universe all|ashare|main|gem，可选 --sw1-name 申万一级行业，可选 --min-days N 排除次新股
python3 eval_factor_standalone.py --save --horizon 5 --universe ashare --limit-dates 120
python3 eval_factor_standalone.py --save --horizon 5 --sw1-name 电子 --limit-dates 120   # 单个行业
python3 eval_factor_standalone.py --save --horizon 5 --universe ashare --no-neutralize    # 只落 raw
for U in all ashare; do for H in 1 5 10 20; do
  python3 eval_factor_standalone.py --save --horizon $H --universe $U --limit-dates 120

```

## 8. 已知边界

- 因子基于**不复权** OHLCV 计算（与筛选策略一致）；做回测研究时收益口径请用 `v_hfq_daily`
- 增量回看 180 自然日装载（覆盖 ma60/mom60 最长窗口），新上市不足 60 日的标的早期因子为 NULL
- 量价因子在近期（2026-07~09）窗口负 IC 显著（高放量/高 OBV 斜率/高量能波动占劣），说明该窗口内"放量追高"风险高——不同窗口结论会变，请以自己跑的评估为准

## 9. 基本面因子（通达信财务数据，2026-09-05 新增）

**数据源**：通达信行情主站（mootdx `get_finance_info`，37 字段），全市场 5,238 只沪深A股同步一次仅约 6 秒（10 线程），免费免登录（系统已依赖 mootdx）。
- 同步：`python sync_fundamental_standalone.py`（落库 `tdx.raw_stock_finance`，按 `(symbol, updated_date)` upsert，**保留历史快照**）
- 因子计算：`python calc_fundamental_standalone.py`（落库 `raw_stock_indicators` 新增列，point-in-time：评估日 ≤ 快照 updated_date 才有值）

**12 个因子**：估值 pe/pb/ps/pcf；盈利 roe/roa/net_margin/op_margin；质量 debt_ratio/cf_quality/ar_ratio/inv_ratio。
- 已知数据特性：本环境财务**总量字段**（净利润/收入/资产）为每股口径的 10 倍，PE/PS/PCF 已内置 ×10 校正；比值因子（ROE/负债率/含金量）天然正确
- `raw_stocks_basic.totalmv` 实测单位为 **元**（非文档旧说的万元；screening 市值打分等均按元口径）

**用法**：
- 每周跑一次 `sync_fundamental_standalone.py`（后台约 6~10 秒全量）→ 快照积累几期后，成长因子（营收/净利同比）可算
- 基本面因子可直接作**筛选条件**（选股页因子条件已含 pe/pb/roe 等 12 个）
- IC 评估：目前只有一期快照（约 2 周日期有值），基本面因子 IC 暂无统计意义；积累几期后跑 `eval_factor_standalone.py --save ...` 自动纳入（列级 NULL 已支持，不影响其他因子）

## 10. 数据质量与口径（数据法医记录 2026-09-05）

评估口径（已修复）：
- **收益处理默认 = 每日截面 1%/99% 分位缩尾 + 截面去均值（超额收益口径）**，修正极端妖股与单边行情对分位组收益（Q1~Q5）的影响
- Spearman 秩 IC 对极端值天然稳健（单调变换不改秩），缩尾/去均值不改变 IC/ICIR 数值
- Q 组收益显示为超额收益（相对当日市场平均），3 位小数；0.000% 表示该组与市场持平，非数据截断

已排查并确认的问题：
1. "Q 组出现 0.00%"：是显示 2 位小数舍入所致（真实值如 0.0047%）；全市场精确 0 收益仅约 0.9%（停牌股价格冻结），非截断
2. "多因子 Q5 集体 ≈4.3%"：真实原因是一段极端单边行情（2026-08-03~08-10 全市场中位数 +3.8%）+ 高动量股同时在多因子取极值；**曾存在 bug：分位累计误用原始收益（pairs[i][1]）而非缩尾/去均值后的收益，已修复**；已抽查验证非次新股、复权因子无跳变
3. "未来函数"：因子仅用 T 日及之前数据（窗口截至 i、OBV/VPT 只累积到 i），收益为 close(T+H)/close(T)，预测未来而非当日；真实局限是入场价按 T 日收盘近似，实盘信号需 T+1 开盘执行
4. 日频截面 IC 常态为 0.01~0.05（0.1 以上为罕见强因子），ICIR 才是显著性指标（|ICIR|>0.3 较优）；115 个交易日为 --limit-dates 120 参数，全量数据约 250 个交易日
5. 未做行业/市值中性化：IC 中混有风格成分，横向比较建议按申万一级分组后看相对强弱
